# Agent notes for this repo

Public, attendee-facing repo for the Internet2 TechEX 2026 tutorial
"Practical AI for Technical Professionals." Attendees clone this repo and open
a coding agent inside a lab folder, so everything here is read by people who
have never seen it and by small local models.

## Things that are deliberate, not gaps

- **README stays thin.** The lab is intentionally undocumented in the README
  ("working out what is in the folder is part of it"). Do not add a lab
  walkthrough, file index, or corpus summary to the README or to the lab
  folder unless the facilitator asks.
- **`lab-1-winterover/raw/` is the attendee's raw source pile.** Fictional
  one-person-IT-shop Antarctic station (Katabatic Station). Mess, duplication,
  stale runbooks, and contradictions in there are the exercise. Do not tidy,
  dedupe, rename, or "fix" the corpus.
- **Everything is fictional and CC0 1.0.** Keep it that way; no real people,
  hosts, credentials, or institutions in lab material.
- **Vendor-neutral.** Attendees use a mix of coding agents and models. Do not
  write agent-specific or model-specific instructions into attendee material.
  Describe roles, not products or model versions.
